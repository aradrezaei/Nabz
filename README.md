# نبض

ارزش تبلیغ در کانال عمومی اپ داخلی را فقط از آمار قابل‌مشاهده حساب می‌کند: بخر، مشروط، یا نخر.

تلگرام پشتیبانی نمی‌شود. صفحهٔ عمومی فقط برای ایتا خوانده می‌شود، چون همان صفحه دنبال‌کننده و ویو را نشان می‌دهد. روبیکا، بله و سروش صفحهٔ عمومی با ویوی پست ندارند؛ برای آن‌ها اسکرپر نیست و ورودی JSON دستی است.

درصد زنده برآورد از روی ویو است، نه سرشماری اکانت‌ها.

## اجرا

```bash
cd ~/Projects/nabz
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

nabz https://eitaa.com/NAME
nabz manual examples/manual-rubika.json
nabz compare nabz-out/a.json nabz-out/b.json
```

اگر ایتا از این شبکه بسته بود:

```bash
nabz https://eitaa.com/NAME --proxy socks5://127.0.0.1:1080
```

قیمت پیشنهادی فقط از میانهٔ ویو است. نرخ پیش‌فرض هر هزار ویو ۱۰۰هزار تومان است و با `--cpm` عوض می‌شود.

پست تازه‌تر از ۱۲ ساعت، پست پین و پیام سیستمی در میانهٔ ویو نمی‌آیند. اگر کمتر از ۸ پست بالغ باشد، درصد قطعی اعلام نمی‌شود. اگر دنبال‌کننده یا ویو در صفحه نباشد، حکم «داده کافی نیست» است.
